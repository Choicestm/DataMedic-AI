# DataMedic-AI

DataMedic AI is an AI-powered dataset analysis tool that allows users to upload CSV files for automatic exploratory data analysis. The application detects data quality issues, including missing values, duplicate records, outliers, and feature correlations, while providing descriptive statistics and visualizations. It recommends the most appropriate machine learning model based on the dataset's characteristics, explains its recommendations, and generates a comprehensive analysis report to support data preprocessing and model selection.
